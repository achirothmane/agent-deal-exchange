# Deal Negotiation Sandbox — experimental D2 boundary prototype

**IMPLEMENTED, NOT YET VERIFIED** until tests run on named SHA / CI. This is intentionally *not* a commerce backend or autonomous LLM agent.

Run without installing dependencies:

```bash
node --test prototype/deal-sim/engine.test.mjs
```

The sandbox demonstrates: confidential per-party price limits, separate offer actors, strictly ordered counteroffers, immutable offer hashes, exact acceptance of same terms by two parties, finite delegation windows, deterministic idempotent proposal replays, and a first-class `NOT_REQUESTED` external-effect state.

It **does not** include: real identity/authentication, signature validation, provider-backed timestamps, dynamic delegation revocation, legally binding human approval, taxes and shipping in canonical term digests, live Medusa APIs, external side effects, settlement reconciliation, LLM negotiation agents, security hardening, concurrency controls or persistent storage.

`actor` and `now` are caller-supplied values intended ONLY for deterministic offline tests. They must come from independently authenticated principals and trusted time sources in any future application.

No user funds, purchase orders, contracts or outbound messages can be generated by this prototype. Its only output is an in-memory **tentative** matching of accepted terms.

Any future move toward a deployable adapter requires explicit authority validation and the two-account authorization tests recorded in `docs/reviews/D1-medusa-upstream-fit.md`.
